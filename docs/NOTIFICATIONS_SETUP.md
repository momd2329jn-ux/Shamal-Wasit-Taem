# إعداد الإشعارات — فريق شمال واسط

## الحالة الحالية

المشروع يحتوي على إشعارات داخل التطبيق تعمل لحظيًا عبر Firestore:

- عند وصول استفسار جديد يظهر عداد للمشرف/المدير.
- عند رد الفريق على استفسار عضو يظهر عداد للعضو.
- يتم تعليم الإشعار كمقروء عند فتح سجل الاستفسارات.
- يوجد زر **تفعيل إشعارات الجهاز** في حساب العضو ولوحة الإدارة.
- عند منح المتصفح الإذن، يمكن عرض إشعار الجهاز أثناء تشغيل الموقع عندما يصل حدث جديد.
- Service Worker وPWA موجودان في المشروع.

## الملفات البرمجية

- `js/notifications.js` — المراقبة والعدادات وإشعارات المتصفح.
- `js/app.js` — القائمة المتجاوبة وزر تفعيل إشعارات الجهاز وتسجيل Service Worker.
- `sw.js` — التخزين المؤقت وواجهة إشعارات Web Push الأساسية.

## ملاحظة مهمة عن Push الحقيقي

الإشعار الذي يصل إلى الهاتف **والموقع مغلق بالكامل** يحتاج إلى Firebase Cloud Messaging (FCM) مع Backend/Cloud Functions وإدارة FCM Tokens. هذا الجزء ليس شرطًا لتشغيل العدادات والإشعارات داخل الموقع، ولا توجد مفاتيح سرية داخل ملفات الواجهة.

لا تضع Service Account private key أو Firebase Admin SDK credentials داخل ملفات الموقع.
